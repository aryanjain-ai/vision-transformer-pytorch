# Vision Transformer (ViT) in PyTorch

This project implements the Vision Transformer architecture for image classification using PyTorch.

## Features
- Patch embedding using convolution
- CLS token
- Positional embeddings
- Multi-head self-attention
- Transformer encoder blocks
- MLP head for classification

## Model Architecture
- Patch size: 4x4
- Embedding dimension: 256
- Number of heads: 8
- Encoder depth: 6

## Dataset
Trained on CIFAR-10.

## Technologies Used
- Python
- PyTorch
- torchvision
- NumPy

## Status
Completed and open for improvements.
